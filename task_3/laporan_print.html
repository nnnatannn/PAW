1. Deskripsi & Ketentuan Tugas

Berdasarkan modul Pertemuan 4 (Tabel, Formulir, Layout, dan Web Media), tugas individu 3 memiliki kriteria sebagai berikut:

  • Dua Halaman Web:
    • Halaman pendaftaran yang didesain menggunakan form dengan method="GET".
    • Halaman detail informasi pendaftar yang dibuat dalam format data dummy.
  • Desain Query String: Melempar data dari halaman pendaftaran ke halaman detail melalui parameter URL (query string), hanya mendesain query string dan tidak melakukan pemrosesan data backend.
  • Desain Kedua Halaman dengan CSS:
    • Menggunakan minimal 3 jenis selector CSS.
    • Mendesain komponen layout, box model, tabel, dan formulir dengan CSS secara rapi dan estetis.

3. Penjelasan Kode Program

A. Halaman Formulir Pendaftaran (index.html)

Halaman ini dirancang untuk menerima input identitas calon anggota organisasi mahasiswa. Fitur-fitur utama kode:

  • Form Method GET: Didefinisikan dengan tag <form id="form-pendaftaran" action="detail.html" method="GET">. Saat formulir dikirimkan, peramban akan merangkai seluruh nilai kontrol input menjadi Query String di URL menuju ke detail.html.
  • Kontrol Input Beragam:
    • <input type="text" name="nama"> & <input type="text" name="nim">: Untuk input data teks.
    • <input type="email" name="email">: Untuk validasi format email resmi mahasiswa.
    • <input type="radio" name="gender">: Memilih jenis kelamin (Laki-laki / Perempuan).
    • <select name="prodi">: Pilihan program studi menggunakan menu dropdown.
    • <input type="checkbox" name="minat">: Pilihan multipel untuk peminatan divisi.
    • <input type="date" name="tgl_lahir">: Pilihan tanggal lahir.
    • <textarea name="alamat">: Input teks multi-baris untuk alamat tempat tinggal.
    • <button type="submit"> dan <button type="reset">: Tombol aksi pendaftaran.

B. Halaman Detail Informasi Dummy (detail.html)

Halaman ini menampilkan representasi data calon anggota yang telah terdaftar dalam bentuk dummy:

  • Visualisasi Query String: Dilengkapi elemen box #display-query-string yang menampilkan string parameter URL yang dikirimkan dari formulir sebelumnya.
  • Tabel Data Semantik: Menggunakan elemen tabel HTML lengkap (<table>, <thead>, <tbody>, <tfoot>, <th>, <td>).
  • Spanning Columns: Menggunakan atribut colspan="3" pada baris footer (<tfoot>) untuk menggabungkan 3 kolom ringkasan status berkas.
  • Tombol Navigasi: Tautan <a href="index.html" class="btn btn-outline"> untuk mempermudah pengguna kembali ke halaman form.

C. Lembar Gaya CSS (style.css)

Kode CSS mengimplementasikan ketentuan desain tingkat lanjut dari materi P4:

Komponen / Kriteria Implementasi pada CSS
Minimal 3 Selector 1. Element Selector (body, h1, table, th, td)
2. Class Selector (.card, .form-control, .custom-table, .btn)
3. ID Selector (#form-section, #detail-section)
4. Pseudo-class (:hover, :focus, :nth-child(even))
5. Attribute Selector (input[type="radio"], input[type="checkbox"])
Box Model Menggunakan box-sizing: border-box, padding: 2rem, border-radius: 16px, dan drop-shadow bertingkat (box-shadow).
Layout Responsif Penerapan Flexbox pada kontainer utama dan baris form (.form-row), serta Media Query untuk layar seluler (≤ 640px).
Styling Tabel Menerapkan border-collapse: collapse, zebra striping (warna latar baris genap bergantian), serta efek interaktif hover warna biru muda pada baris tabel saat kursor melintas.
